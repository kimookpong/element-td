## Element TD 3D v1.1.1

อัปเดตเล็ก ๆ หลังเปิดระบบออนไลน์ เล่นได้ที่ **https://elementtd.thasala.dev**

### มีอะไรใหม่

- **จำนวนผู้เล่น** หน้าแรกแสดงจำนวนผู้เล่นที่ลงทะเบียนต่อจาก "by kimookpong" ทั้งบนคอมและมือถือ
- **ปุ่มล็อกอิน Google** ไม่มีกรอบสีขาวบนพื้นหลังสีเข้มแล้ว
- **Open source** โค้ดใช้สัญญาอนุญาต MIT ส่วนเพลงและภาพสงวนลิขสิทธิ์ (ดู `LICENSE` และ `NOTICE`)
- ย้าย Worker และฐานข้อมูลไปอยู่บัญชี Cloudflare เดียวกับโดเมน และ deploy ด้วย `npm run deploy`

### English

A small follow-up to the online release at https://elementtd.thasala.dev: the title screen now shows how many players have signed up (on desktop and mobile), the Google sign-in button no longer sits in a white box on the dark panel, and the code is now MIT licensed (music and art remain all rights reserved, see `NOTICE`).
