# Element TD 3D — หกธาตุพิทักษ์

เกม Tower Defense แบบ 3D เล่นบนเบราว์เซอร์ ได้แรงบันดาลใจจาก **Element TD (Warcraft III)**
จุดขายคือพลังของ **6 ธาตุ**: ✨ แสง · 🌑 มืด · 💧 น้ำ · 🔥 ไฟ · 🌪️ ลม · 🪨 ดิน

สร้างด้วย **[Three.js](https://threejs.org/)** (WebGL) + **[Vite](https://vite.dev/)** — กราฟิกทั้งหมดสร้างด้วยโค้ด ไม่มีไฟล์ภาพ/โมเดลภายนอก

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev       # เปิดเซิร์ฟเวอร์พัฒนา http://localhost:5173
npm run build     # สร้างไฟล์สำหรับขึ้นเว็บไว้ในโฟลเดอร์ dist/
npm run preview   # ทดลองเปิดไฟล์ที่ build แล้ว
```

โฟลเดอร์ `dist/` เป็นไฟล์ static ทั้งหมด นำไปขึ้น Vercel / Netlify / GitHub Pages ได้ทันที

## กลไกเกม (แบบ Element TD)

| ระบบ | รายละเอียด |
|---|---|
| **ผลึกธาตุ 🔮** | เริ่มเกมได้ 1 ชิ้น และได้เพิ่มทุก 5 เวฟ ใช้ปลดล็อกธาตุหรือเพิ่มเลเวลธาตุ (สูงสุด 3) — เลือกเส้นทางธาตุให้ดี เพราะไม่พอสำหรับทุกธาตุ |
| **ป้อมพื้นฐาน** | 🏹 ธนู / 💣 ปืนใหญ่ สร้างได้ทันที ไม่มีธาตุ (ดาเมจ ×1 กับทุกตัว) |
| **ป้อมธาตุเดี่ยว** | สร้างได้เมื่อปลดล็อกธาตุ อัปเกรดได้ 3 ระดับ แต่ **ระดับป้อม ≤ เลเวลธาตุ** |
| **ป้อมสองธาตุ (15)** | เพิ่มธาตุที่สองให้ป้อมธาตุเดี่ยว เช่น ไอน้ำเดือด, แมกมา, พายุหิมะ, สุริยคราส |
| **ป้อมสามธาตุ (20)** | เพิ่มธาตุที่สามให้ป้อมสองธาตุ เช่น หม้อแม่มด, ต้นไม้แห่งชีวิต, อุกกาบาต, ซูเปอร์โนวา |
| **เขาวงกต** | ในแผนที่ลานหิน มอนสเตอร์ใช้ pathfinding เดินอ้อมป้อม ต้องผ่านจุดตรวจ ①②  ตามลำดับ — ห้ามปิดทางทั้งหมด |
| **ความสามารถมอนสเตอร์** | ว่องไว · เกราะหิน (ต้านสถานะ) · ฟื้นฟู · แยกร่าง · อมตะ (ฟื้นคืนชีพ) · บินได้ (ข้ามเขาวงกต) · บอสมังกรทุก 10 เวฟ |
| **ดอกเบี้ย** | จบเวฟได้ดอกเบี้ย 3% ของทองที่เก็บไว้ |

### วงจรธาตุ

**แสง → มืด → น้ำ → ไฟ → ลม → ดิน → แสง** (ชนะทาง ×2 · โดนแพ้ทาง ×0.5)

| ธาตุ | ความสามารถ |
|---|---|
| 🔥 ไฟ | ระเบิดวงกว้าง + เผาไหม้ต่อเนื่อง |
| 💧 น้ำ | ชะลอความเร็ว |
| 🪨 ดิน | ดาเมจหนัก มีโอกาสทำให้มึนงง |
| 🌪️ ลม | ยิงหลายเป้าพร้อมกัน ผลักถอยหลัง |
| ✨ แสง | ลำแสงระยะไกล ทะลุทุกตัวในแนว |
| 🌑 มืด | สาปให้รับดาเมจเพิ่ม + ดาเมจตาม % HP |

ป้อมหลายธาตุได้ความสามารถของทุกธาตุรวมกัน และนับเป็นทุกธาตุเวลาคำนวณความได้เปรียบ

## กราฟิก

- ภูมิประเทศสไตล์แฟนตาซี: เนินหญ้า, **ทางเดินหินที่ลึกลงไปพร้อมกำแพงอิฐกันดิน**, ต้นไม้, ตะเกียง, บ่อน้ำ, ซากปรักหักพัง
- พอร์ทัลน้ำวนสีฟ้า (จุดเกิด) และสีแดง (แกนกลาง) ด้วย shader
- ป้อมบนฐานหินขอบเรืองแสงตามสีธาตุ: เตาไฟทองคำ, อ่างน้ำลอย, คริสตัลดิน, กังหันลม, คริสตัลแสงลอย, หม้อแม่มด
- มอนสเตอร์มีแอนิเมชัน: หมาป่าคริสตัล, โกเลมหิน, สไลม์, มังกรบิน, บอสมังกร
- ลูกศรแสดงเส้นทางของมอนสเตอร์แบบเรียลไทม์ (ช่วยวางแผนเขาวงกต)
- 4 ฉาก: ลานวงกตทุ่งหญ้า, ซากปราการโบราณ, หุบเขาทะเลทราย, ห้วงมืดกลางคืน
- ปุ่ม ✨/⚡ สลับคุณภาพกราฟิก (โหมดประหยัดปิดเงาและ bloom)

## การควบคุม

| การกระทำ | เมาส์ | มือถือ |
|---|---|---|
| วางป้อม / เลือกป้อม | คลิกซ้าย | แตะ |
| หมุนกล้อง | คลิกขวาค้างแล้วลาก | สองนิ้วลาก |
| ซูม | ล้อเมาส์ | บีบสองนิ้ว |
| รีเซ็ตกล้อง | ปุ่ม 🎥 หรือ `C` | ปุ่ม 🎥 |

คีย์ลัด: `1–8` เลือกป้อม · `Space` เริ่มเวฟ · `U` อัปเกรด · `S` ขาย · `T` โหมดเล็งเป้า · `F` ความเร็ว · `P` หยุด · `M` เสียง · `Esc` ยกเลิก

## โครงสร้างโค้ด

```
index.html         หน้าเกม + UI
src/main.js        UI, อินพุต, ลูปหลัก
src/sim.js         ตรรกะเกมทั้งหมด (pathfinding, ป้อม, มอนสเตอร์, เวฟ) — ไม่ขึ้นกับการเรนเดอร์
src/data.js        ข้อมูลธาตุ, ป้อม, ราคา, ความสามารถมอนสเตอร์, แผนที่ (ปรับสมดุลเกมที่นี่)
src/render3d.js    ตัวเรนเดอร์ Three.js: กล้อง, เอฟเฟกต์, อนุภาค, ซิงก์วัตถุจาก sim
src/world.js       สร้างฉากแผนที่: ภูมิประเทศ, กำแพง, พอร์ทัล, ต้นไม้, ของตกแต่ง
src/models.js      โมเดลป้อมและมอนสเตอร์พร้อมแอนิเมชัน
src/textures.js    พื้นผิว procedural (หญ้า, หินปูถนน, อิฐ, วงรูน)
src/gfx.js         ตัวช่วยกราฟิกที่ใช้ร่วมกัน
src/audio.js       เสียงเอฟเฟกต์ (WebAudio)
src/style.css      สไตล์ UI แฟนตาซี
```

### แผนที่

แผนที่เขียนเป็นตัวอักษร 20×12 ใน `src/data.js`:
`.` ลานหิน (เดินได้+สร้างได้) · `#` เนินหญ้า (สร้างได้) · `=` ทางเดิน · `R` โขดหิน · `W` ซากกำแพง · `S` จุดเกิด · `C` แกนกลาง · `1`–`9` จุดตรวจ
