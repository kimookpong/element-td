# Element TD 3D — หกธาตุพิทักษ์

เกม Tower Defense แบบ 3D เล่นบนเบราว์เซอร์ ได้แรงบันดาลใจจาก **Element TD (Warcraft III)**
จุดขายคือพลังของ **6 ธาตุ**: ✨ แสง · 🌑 มืด · 💧 น้ำ · 🔥 ไฟ · 🌪️ ลม · 🪨 ดิน

สร้างด้วย **[Three.js](https://threejs.org/)** (WebGL) + **[Vite](https://vite.dev/)** — กราฟิกทั้งหมดสร้างด้วยโค้ด ไม่มีไฟล์ภาพ/โมเดลภายนอก

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev       # เปิดเซิร์ฟเวอร์พัฒนา http://localhost:5173
npm run build     # สร้างไฟล์สำหรับขึ้นเว็บไว้ในโฟลเดอร์ dist/
npm run preview   # ทดลองเปิดไฟล์ที่ build แล้ว
```

โฟลเดอร์ `dist/` เป็นไฟล์ static ทั้งหมด นำไปขึ้น Vercel / Netlify / GitHub Pages ได้ทันที

## กลไกเกม (แบบ Element TD)

| ระบบ | รายละเอียด |
|---|---|
| **100 เวฟ** | HP มอนสเตอร์ช่วงเวฟ 1–30 โตเร็ว (+17%/เวฟ) หลังจากนั้นโตตามทองที่ผู้เล่นหาได้ (ค่อย ๆ ชะลอจน ~2%/เวฟ ช่วงท้าย) — เวฟ 100 ≈ 16 เท่าของเวฟ 30 · จบเวฟ 100 แล้วเล่นต่อแบบไม่รู้จบได้ |
| **เวฟทีละเวฟ** | เวฟแรกมาหลังเริ่มเกม 30 วิ — **เวฟถัดไปปล่อยเมื่อเคลียร์สนามหมดแล้ว 10 วิ** เวฟไม่ซ้อนกัน · ผู้เล่นมีแค่ **เริ่มเกม / หยุดชั่วคราว** |
| **มอนสเตอร์วนรอบ** | ตัวที่หลุดถึงประตูแกนกลาง **เสีย 1 ชีวิตต่อตัวเสมอ** (มอนสเตอร์ทั่วไป บอส หรือภูตธาตุก็ตาม) แล้ว **วนกลับไปเริ่มที่ประตูทางเข้าใหม่** จนกว่าจะถูกกำจัด |
| **เวลาก่อสร้าง** | วางป้อมใช้เวลา 2.5–3.5 วิ อัปเกรด/หลอมธาตุใช้ 3.5–10 วิ — ระหว่างก่อสร้างป้อม **โจมตีไม่ได้** (มีนั่งร้านและแถบความคืบหน้า) · ขายระหว่างสร้างครั้งแรกได้เงินคืนเต็ม |
| **ระดับป้อม** | ป้อมแต่ละระดับมีขนาดและรูปทรงต่างกันชัดเจน เช่น ป้อมธนู: หอไม้มุงจาก → หอหิน → ป้อมปราการคู่หน้าไม้ |
| **ผลึกธาตุ & ภูตธาตุ** | เริ่มเกมได้ 1 ชิ้น และได้เพิ่มทุก 5 เวฟ — กดที่ธาตุเพื่อ **เรียกภูตพิทักษ์ธาตุ** (มังกรสีธาตุนั้น) เมื่อกำจัดได้จึง **ปลดล็อก/เพิ่มเลเวลธาตุ** (สูงสุด 3) · HP ภูต = HP มอนสเตอร์เวฟถัดไป ×5/×10/×16 ตามเลเวล · หลุดเสีย 1 ชีวิตต่อรอบ และเวฟถัดไปจะรอจนกว่าภูตถูกกำจัด |
| **ป้อมพื้นฐาน** | ธนู / ปืนใหญ่ สร้างได้ทันที ไม่มีธาตุ (ดาเมจ ×1 กับทุกตัว) |
| **ป้อมธาตุเดี่ยว** | สร้างได้เมื่อปลดล็อกธาตุ อัปเกรดได้ 3 ระดับ แต่ **ระดับป้อม ≤ เลเวลธาตุ** |
| **ป้อมสองธาตุ (15)** | เพิ่มธาตุที่สองให้ป้อมธาตุเดี่ยว — ทุกคู่ธาตุมีป้อมของตัวเอง |
| **ป้อมสามธาตุ (4)** | เพิ่มธาตุที่สามได้เฉพาะสูตร น้ำ/ไฟ/ลม/ดิน: พายุลาวา, ปล่องปะทุ, ธารน้ำแข็ง, ฝนอุกกาบาต |
| **เขาวงกต** | ในแผนที่ลานหิน มอนสเตอร์ใช้ pathfinding เดินอ้อมป้อม ต้องผ่านจุดตรวจ ①②  ตามลำดับ — ห้ามปิดทางทั้งหมด |
| **ความสามารถมอนสเตอร์** | ว่องไว · เกราะหิน (ต้านสถานะ) · ฟื้นฟู · แยกร่าง · อมตะ (ฟื้นคืนชีพ) · บินได้ (ข้ามเขาวงกต) · บอสมังกรทุก 10 เวฟ (HP ×12) — **ฆ่าได้รับชีวิตคืน +1** |
| **ดอกเบี้ย** | จบเวฟได้ดอกเบี้ย 3% ของทองที่เก็บไว้ |
| **2 ภาษา (ไทย / English)** | สลับภาษาได้ด้วยปุ่ม TH/EN ที่เมนูหลักและแถบบน หรือกด `L` — จำค่าไว้ในเบราว์เซอร์ (ครั้งแรกเลือกตามภาษาเครื่อง) ข้อความทั้งหมดอยู่ใน `src/i18n.js` และฟิลด์ `en` ของข้อมูลเกม |
| **ป้ายผู้สร้าง** | ป้ายไม้มุมแผนที่พร้อมรูปโปรไฟล์ GitHub ของผู้พัฒนา คลิกเพื่อไปที่ [kimookpong.github.io](https://kimookpong.github.io/) |
| **บันทึกอัตโนมัติ** | บันทึกลงเบราว์เซอร์ทุกครั้งที่ไม่มีมอนสเตอร์ในสนาม (สร้าง/อัปเกรด/ขายป้อม, จบเวฟ) — รีเฟรชหรือปิดแล้วกด **เล่นต่อ** ที่เมนูได้ ถ้ารีเฟรชกลางเวฟจะกลับไปจุดที่บันทึกล่าสุด |

### วงจรธาตุ

**แสง → มืด → น้ำ → ไฟ → ลม → ดิน → แสง** (ชนะทาง ×2 · โดนแพ้ทาง ×0.5)

### ป้อมธาตุทั้ง 25 แบบ

แต่ละป้อมมีรูปแบบการโจมตีของตัวเอง (ลำแสงชาร์จทั่วแผนที่, ลำแสงชิ่ง, ลำแสงต่อเนื่อง, คลื่น, กรวย, แอ่ง/บ่อบนพื้น, พายุเคลื่อนตามทาง, จุดปะทุหน่วงเวลา, ฝนอุกกาบาต ฯลฯ) และนับเป็นทุกธาตุที่มีเวลาคำนวณความได้เปรียบ

#### ธาตุเดี่ยว — 6 ป้อม

| ธาตุ | ป้อม / รูปลักษณ์ | การโจมตีและสถานะเด่น | จุดอ่อน |
|---|---|---|---|
| แสง | **สุริยเนตร** — หอคอยขาวทอง มีผลึกแสงกลางวงแหวน | ชาร์จลำแสงยิงเป้าหมายเดียวได้ทั่วแผนที่ ดาเมจต่อครั้งสูง เหมาะกับเก็บตัวหลุด | ยิงช้ามาก รับมือฝูงไม่ดี |
| มืด | **เนตรอเวจี** — กรงเล็บหินดำโอบลูกแก้วม่วง | ยิงพลังมืดแรง พร้อมกัดกร่อนชีวิต ทำดาเมจต่อเนื่องตาม %HP ปัจจุบัน | ระยะปานกลาง คำสาปเบาลงเมื่อศัตรูเลือดน้อย |
| น้ำ | **วังวนธารา** — อ่างน้ำทรงเตี้ย มีเกลียวคลื่นลอยเหนือป้อม | ยิงน้ำกระจายเป็นวง ดาเมจเบา ติดเปียกชุ่ม ลดความเร็วเคลื่อนที่ | ดาเมจต่ำ ต้องพึ่งป้อมอื่นฆ่า |
| ไฟ | **เตาอัคคี** — เตาอิฐดำกับปืนใหญ่ทองแดง | ยิงลูกไฟระเบิดวงกว้าง พร้อมเผาไหม้ต่อเนื่อง | กระสุนเดินทางช้า ศัตรูเร็วอาจพ้นจุดระเบิด |
| ลม | **จักรวายุ** — ใบมีดสามชิ้นโคจรรอบแกนลม | ยิงรัวหลายเป้าหมาย สะสมการยิงเพื่อปล่อยลมผลักถอยตามทางเดิน | ดาเมจต่อเป้าต่ำ บอสต้านแรงผลัก |
| ดิน | **หมัดปฐพี** — โกเลมหินหมัดใหญ่ มีผลึกอำพัน | ขว้างหินหนัก มีโอกาสมึนงง หยุดการเดินและใช้สกิลชั่วคราว | ระยะสั้น ยิงช้า สตันไม่แน่นอน |

#### ป้อมผสม 2 ธาตุ — 15 ป้อม

| ธาตุ | ป้อม / รูปลักษณ์ | การโจมตีและสถานะเด่น | จุดอ่อน |
|---|---|---|---|
| มืด + แสง | **คราสพิพากษา** — วงแหวนทองล้อมดวงอาทิตย์ดำ | ยิงสะสมตราคราสบนเป้าเดียว ครบจำนวนแล้วระเบิดดาเมจตาม HP ที่เป้าหมายเสียไป | ไม่คุ้มกับตัวเลือดเต็มหรือตัวที่ตายก่อนสะสมตราครบ |
| แสง + น้ำ | **ปริซึมธารา** — ผลึกใสล้อมด้วยหยดน้ำลอยตัว | ลำแสงหักเหชิ่งระหว่างศัตรู พร้อมสโลว์เบา ๆ ดาเมจลดลงทุกครั้งที่ชิ่ง | ศัตรูอยู่ห่างกันจะชิ่งไม่ได้ |
| ไฟ + แสง | **สุริยะเผาผลาญ** — หอรวมแสง มีแกนดวงอาทิตย์ | ยิงลำแสงต่อเนื่อง ยิ่งโจมตีเป้าเดิมนานยิ่งร้อนและแรง | เปลี่ยนเป้าแล้วพลังสะสมรีเซ็ต |
| แสง + ลม | **ศรแสง** — หน้าไม้ลอยตัว มีปีกลม | ยิงศรแสงความเร็วสูง ทะลุศัตรูเป็นเส้นตรง | ต้องวางให้แนวยิงตรงกับทางเดิน |
| ดิน + แสง | **เสาศิลารุ่งอรุณ** — เสาหินรูน มีผลึกทองบนยอด | ยิงช้า พร้อมปล่อยคลื่นเปิดเผยจุดอ่อน ทำให้ศัตรูรับดาเมจจากการโจมตีโดยตรงเพิ่ม | ดาเมจตัวเองต่ำ ต้องมีป้อมอื่นยิงร่วม |
| มืด + น้ำ | **บ่ออาถรรพ์** — บ่อน้ำดำกับวังวนม่วง | สร้างบ่อคำสาปกัดกร่อน ยิ่งอยู่ในบ่อนาน ดาเมจตาม %HP ปัจจุบันยิ่งแรงจนถึงเพดาน | ศัตรูเร็วผ่านบ่อก่อนคำสาปรุนแรง |
| มืด + ไฟ | **เพลิงวิญญาณ** — เตาหัวกะโหลก มีไฟม่วงแดง | ติดไฟคำสาป หากเป้าหมายตาย ไฟที่เหลือแพร่ไปยังศัตรูใกล้เคียง | ประสิทธิภาพลดลงเมื่อศัตรูเดินกระจาย |
| มืด + ลม | **วังวนสูญญะ** — วงแหวนแตกโคจรรอบหลุมดำ | สร้างแรงดึงศัตรูตามทางเข้าหาศูนย์กลาง เพื่อรวมฝูง | ดาเมจต่ำ บอสต้านแรงดึง |
| มืด + ดิน | **สุสานพันธนาการ** — หลุมศพหินดำ มีโซ่เงาจากพื้น | ตรึงเป้าหมายให้อยู่กับที่ พร้อมคำสาปกัดกร่อน | ศัตรูที่ถูกตรึงยังใช้สกิลได้ รอบโจมตีนาน |
| ไฟ + น้ำ | **บ่อลาวา** — เตาภูเขาไฟ มีรางน้ำและลาวาไหล | ทิ้งแอ่งลาวา ทำดาเมจต่อเนื่อง ติดหนืดและเผาไหม้ | ต้องให้ศัตรูอยู่ในแอ่งนานจึงคุ้ม |
| น้ำ + ลม | **พายุเหมันต์** — ผลึกน้ำแข็งกลางวงพายุ | พายุหิมะสะสมความเย็นจนเต็มแล้วแช่แข็ง | ต้องใช้เวลาสะสม และมีช่วงต้านทานการแช่ซ้ำ |
| ดิน + น้ำ | **บึงดูด** — บ่อโคลนล้อมด้วยเสาหิน | สร้างโคลนติดจมโคลน ยิ่งอยู่ในพื้นที่นานยิ่งเดินช้า | ดาเมจต่ำ ไม่เด่นกับทางผ่านสั้น ๆ |
| ไฟ + ลม | **พายุเพลิง** — กังหันโลหะโอบกรวยไฟ | ปล่อยพายุไฟเคลื่อนตามทาง เผาศัตรูที่สัมผัสต่อเนื่อง | พายุมีอายุจำกัด อาจเคลื่อนไปยังช่วงที่ไม่มีศัตรู |
| ดิน + ไฟ | **ปืนหลอมเกราะ** — ปืนใหญ่เหล็กบนฐานเตาหิน | ยิงกระสุนร้อนหนัก ระเบิดวงเล็ก ติดเกราะแตก ลดเกราะชั่วคราว | ยิงช้า ประโยชน์ลดลงกับศัตรูไร้เกราะ |
| ดิน + ลม | **พายุทราย** — เสาหินทรายกับวงหินบด | ยิงทรายเป็นกรวย สะสมกัดเซาะจนครบแล้วขัดจังหวะสกิลที่กำลังร่าย | ระยะสั้น ต้องหันกรวยให้ครอบคลุมฝูง |

#### ป้อมผสม 3 ธาตุ — 4 ป้อม

| ธาตุ | ป้อม / รูปลักษณ์ | การโจมตีและสถานะเด่น | จุดอ่อน |
|---|---|---|---|
| ไฟ + น้ำ + ลม | **พายุลาวา** — เกลียวลาวาหมุนรอบแกนไอน้ำ | ปล่อยพายุลาวาเคลื่อนตามทาง ทิ้งแอ่งด้านหลัง ศัตรูติดหนืดและเผาไหม้ | ดาเมจเน้นสะสม พื้นที่ด้านหลังคงอยู่ไม่นาน |
| ดิน + ไฟ + น้ำ | **ปล่องปะทุ** — เนินหินแตกร้าว มีลาวาและช่องไอน้ำ | วางจุดปะทุบนทาง หน่วงเวลาก่อนระเบิดแรง ทำให้มึนงงช่วงสั้น และทิ้งแอ่งลาวา | ศัตรูเร็วอาจผ่านจุดก่อนปะทุ คูลดาวน์นาน |
| ดิน + น้ำ + ลม | **ธารน้ำแข็ง** — กังหันศิลาหุ้มผลึกน้ำแข็ง | สร้างแนวพายุเย็น สะสมจนแช่แข็ง เมื่อยิงซ้ำใส่ตัวที่แข็งจะเกิดน้ำแข็งแตก ทำดาเมจรอบตัวและจบสถานะแช่แข็ง | ต้องโจมตีหลายครั้ง ศัตรูต้านความเย็นทำให้คอมโบเกิดยาก |
| ดิน + ไฟ + ลม | **ฝนอุกกาบาต** — วงหินลอยเหนือปล่องเพลิง | ระดมหินไฟลงพื้นที่ แต่ละลูกระเบิดและเผาไหม้ ลูกหลักสร้างแรงกระแทกขัดจังหวะสกิล | มีเวลารอกระสุนตก กระจายดาเมจจึงไม่เด่นกับเป้าเดี่ยว |

**สถานะ:** มึนงง/แช่แข็ง = หยุดเดินและใช้สกิลไม่ได้ · ตรึง = หยุดเดินแต่ยังใช้สกิล · ขัดจังหวะ = ใช้สกิลไม่ได้ชั่วคราว
(สกิลมอนสเตอร์ = ไฮดราฟื้นฟูเลือด, ฟีนิกซ์ฟื้นคืนชีพ — ถ้าตายขณะโดนขัดจังหวะจะไม่ฟื้น) · เต่ามังกรต้านสถานะควบคุม เว้นแต่โดน **เกราะแตก**

## กราฟิก

- ภูมิประเทศสไตล์แฟนตาซี: เนินหญ้า, **ทางเดินหินที่ลึกลงไปพร้อมกำแพงอิฐกันดิน**, ต้นไม้, ตะเกียง, บ่อน้ำ, ซากปรักหักพัง
- พอร์ทัลน้ำวนสีฟ้า (จุดเกิด) และสีแดง (แกนกลาง) ด้วย shader
- ป้อมทั้ง 25 แบบมีโมเดลเฉพาะตามคำบรรยาย (เตาอิฐกับปืนใหญ่ทองแดง, โกเลมหินหมัดใหญ่, กรงเล็บหินดำโอบลูกแก้ว, ดวงอาทิตย์ดำในวงแหวนทอง, เตาหัวกะโหลก, ภูเขาไฟลาวา ฯลฯ)
- เอฟเฟกต์เฉพาะแต่ละป้อม: แอ่งลาวา/บ่อคำสาป/โคลน/หลุมดำบนพื้น, พายุไฟเคลื่อนตามทาง, อุกกาบาตตกจากฟ้า, น้ำแข็งแตก, ลำแสงชิ่ง และสถานะบนตัวมอนสเตอร์ (ก้อนน้ำแข็ง, โซ่ตรวน, ตราคราส)
- มอนสเตอร์เป็นสัตว์ในเทพนิยาย มีโครงกระดูกและแอนิเมชัน (เดิน/วิ่งควบ/กระพือปีก/ส่ายคอ/สะบัดหาง):
  🐺 หมาป่าคริสตัล (ปกติ) · 🦄 ยูนิคอร์น (ว่องไว) · 🐢 เต่ามังกร (เกราะหิน) · 🐍 ไฮดรา 3 หัว (ฟื้นฟู) ·
  🦊 คิทสึเนะ 3 หาง (แยกร่าง) · 🔥 ฟีนิกซ์ (อมตะ) · 🦅 กริฟฟิน (บินได้) · 🐉 มังกรโบราณ (บอส)
- ลูกศรแสดงเส้นทางของมอนสเตอร์แบบเรียลไทม์ (ช่วยวางแผนเขาวงกต)
- 8 ฉาก: ลานวงกตทุ่งหญ้า, ซากปราการโบราณกลางทะเลทราย (พีระมิด สฟิงซ์), หุบเขาคดเคี้ยว, ห้วงมืดกลางคืน และแผนที่ประจำธาตุ 4 แผนที่:
  - **ภูเขาไฟลาวา** (ไฟ) — เขาวงกตรอบธารลาวา ภูเขาไฟพ่นควัน หินออบซิเดียน ถ่านไฟลอย
  - **แม่น้ำไหลวน** (น้ำ) — ทางเดินเป็นสายน้ำคดเคี้ยว 4 ชั้น มอนสเตอร์ลุยน้ำ น้ำตกต้นสาย กกริมน้ำ ใบบัว
  - **ก้อนเมฆ** (ลม) — เขาวงกตบนเกาะเมฆ มีช่องโหว่มองเห็นท้องฟ้า เกาะลอยฟ้า สายรุ้ง สายลมพัด
  - **ใต้ดิน** (ดิน) — อุโมงค์ในถ้ำมืด หินงอก คริสตัลและเห็ดเรืองแสง
  - แผนที่ประจำธาตุ: มอนสเตอร์ธาตุนั้นมาบ่อย (~50% ของเวฟ) และป้อมที่มีธาตุนั้นได้ **พลังถิ่น +15%**
- ปุ่ม ✨/⚡ สลับคุณภาพกราฟิก (โหมดประหยัดปิดเงาและ bloom)

## SEO และการแชร์

- `index.html`: title/description ภาษาไทย+อังกฤษ, keywords, canonical, hreflang (`?lang=th` / `?lang=en`), Open Graph + Twitter Card (รูปแชร์ `public/og-image.jpg` 1200×630), ข้อมูลโครงสร้าง JSON-LD แบบ `VideoGame` และข้อความอธิบายเกมแบบซ่อน (`.srOnly`) ให้เครื่องมือค้นหาอ่านได้
- `public/robots.txt`, `public/sitemap.xml` (รวม hreflang และรูปภาพ), `public/manifest.webmanifest` (ติดตั้งเป็นแอปบนมือถือได้) และไอคอน `icon-192.png` / `icon-512.png`
- ลิงก์ `?lang=en` เปิดเกมเป็นภาษาอังกฤษทันที (ใช้แชร์ให้ผู้เล่นต่างชาติ)
- หลัง deploy แนะนำให้ส่ง sitemap ที่ Google Search Console: `https://kimookpong.github.io/element-td/sitemap.xml`
