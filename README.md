# Element TD — หกธาตุพิทักษ์

เกม Tower Defense เล่นบนเบราว์เซอร์ จุดขายคือพลังของ **6 ธาตุ**: 🪨 ดิน · 💧 น้ำ · 🌪️ ลม · 🔥 ไฟ · ✨ แสง · 🌑 มืด

เขียนด้วย HTML5 Canvas + JavaScript ล้วน ไม่ต้องติดตั้งหรือ build อะไรเลย

## วิธีเล่น

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที หรือรันเซิร์ฟเวอร์ง่าย ๆ:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ขึ้นเว็บด้วย GitHub Pages / Vercel / Netlify ได้เลยเพราะเป็นไฟล์ static ทั้งหมด

## ระบบธาตุ

| ธาตุ | ราคา | ความสามารถ | ชนะทาง |
|------|------|------------|--------|
| 🔥 ไฟ | 60 | ระเบิดวงกว้าง + เผาไหม้ต่อเนื่อง | 🌪️ ลม |
| 💧 น้ำ | 50 | ทำให้ศัตรูช้าลง | 🔥 ไฟ |
| 🪨 ดิน | 70 | ดาเมจหนัก มีโอกาสทำให้มึนงง | 💧 น้ำ |
| 🌪️ ลม | 55 | ยิงรัวหลายเป้า มีโอกาสผลักถอยหลัง | 🪨 ดิน |
| ✨ แสง | 80 | ลำแสงระยะไกล ทะลุทุกตัวในแนว | 🌑 มืด |
| 🌑 มืด | 75 | สาปให้รับดาเมจเพิ่ม + ดาเมจตาม % HP | ✨ แสง |

- วงจร: **ไฟ → ลม → ดิน → น้ำ → ไฟ** และ **แสง ⇄ มืด**
- ชนะทาง ×1.75 · ธาตุเดียวกัน ×0.5 · โดนแพ้ทาง ×0.65
- ศัตรูทุกตัวมีธาตุประจำตัว ดูแถบ "เวฟถัดไป" เพื่อเลือกป้อมให้ถูกทาง

### การหลอมรวม (Fusion)

อัปเกรดป้อมถึงเลเวล 3 แล้วหลอมรวมกับป้อมเลเวล 3 ต่างธาตุ ได้ป้อมใหม่ที่มีความสามารถของทั้งสองธาตุ
และนับเป็นทั้งสองธาตุเวลาคำนวณความได้เปรียบ — มีทั้งหมด 15 แบบ เช่น
ไอน้ำเดือด (ไฟ+น้ำ), แมกมา (ไฟ+ดิน), พายุหิมะ (น้ำ+ลม), อัสนี (ลม+แสง), สุริยคราส (แสง+มืด)
ป้อมหลอมรวมยัง "ปลุกพลัง" เพิ่มได้อีก 3 ดาว

## ฟีเจอร์

- 3 แผนที่ · 3 ระดับความยาก · 30 เวฟ + โหมดไม่รู้จบ · บอสทุก 10 เวฟ
- ศัตรู 5 แบบ: ทหาร, นักวิ่ง, ยักษ์, ฝูง, บอสธาตุ
- โหมดเล็งเป้า (หัวแถว/ท้ายแถว/HP มากสุด/ใกล้สุด), เร่งความเร็ว 1–3×, หยุดชั่วคราว
- เสียงสังเคราะห์ด้วย WebAudio, บันทึกสถิติสูงสุดในเบราว์เซอร์
- รองรับมือถือ (แตะเพื่อวาง/เลือกป้อม)

## คีย์ลัด

`1–6` เลือกธาตุ · `Space` เริ่มเวฟ · `U` อัปเกรด · `S` ขาย · `T` โหมดเล็งเป้า · `F` ความเร็ว · `P` หยุด · `M` เสียง · `Esc` ยกเลิก

## โครงสร้างไฟล์

```
index.html      หน้าเกม + UI
css/style.css   สไตล์
js/data.js      ข้อมูลธาตุ, การหลอมรวม, ศัตรู, แผนที่, ระดับความยาก (ปรับสมดุลเกมที่นี่)
js/audio.js     เสียงเอฟเฟกต์
js/game.js      เอนจินเกม (ลูป, ป้อม, ศัตรู, เรนเดอร์, อินพุต)
```
