# Element TD 3D — หกธาตุพิทักษ์

เกม Tower Defense แบบ 3D เล่นบนเบราว์เซอร์ จุดขายคือพลังของ **6 ธาตุ**: 🪨 ดิน · 💧 น้ำ · 🌪️ ลม · 🔥 ไฟ · ✨ แสง · 🌑 มืด

สร้างด้วย **[Three.js](https://threejs.org/)** (WebGL) + **[Vite](https://vite.dev/)**

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev       # เปิดเซิร์ฟเวอร์พัฒนา http://localhost:5173
npm run build     # สร้างไฟล์สำหรับขึ้นเว็บไว้ในโฟลเดอร์ dist/
npm run preview   # ทดลองเปิดไฟล์ที่ build แล้ว
```

โฟลเดอร์ `dist/` เป็นไฟล์ static ทั้งหมด นำไปขึ้น Vercel / Netlify / GitHub Pages ได้ทันที
(Vercel ตรวจจับ Vite ให้อัตโนมัติ)

> เปิดผ่านเซิร์ฟเวอร์เท่านั้น — การดับเบิลคลิก `index.html` จะใช้ไม่ได้เพราะเป็น ES modules

## กราฟิก 3D

- โมเดลป้อมไม่ซ้ำกันทั้ง 6 ธาตุ (เตาไฟ, ลูกแก้วน้ำ, ปืนใหญ่หิน, กังหันลม, เสาโอเบลิสก์แสง, ลูกแก้วมืดกับวงแหวน) และโตขึ้นตามเลเวล
- ป้อมหลอมรวมมีวงแหวนธาตุที่สองและลูกพลังโคจรรอบ
- ศัตรู 5 แบบ (ทหาร, นักวิ่ง, ยักษ์มีเขา, ฝูง, บอสหนามมีออร่า) พร้อมเอฟเฟกต์สถานะ: ชะลอ, มึนงง, สาป, เผาไหม้
- แสงเงาแบบ real-time, bloom ให้พลังธาตุเรืองแสง, ระบบอนุภาค, ลำแสง, วงระเบิด
- 3 ฉาก: ทุ่งหญ้ามีป่าสน, หุบเขาหินทราย, ห้วงมืดกลางคืนมีคริสตัล
- ปุ่ม ✨/⚡ สลับคุณภาพกราฟิก (โหมดประหยัดปิดเงาและ bloom สำหรับมือถือ/เครื่องสเปกต่ำ)

### การควบคุม

| การกระทำ | เมาส์ | มือถือ |
|---|---|---|
| วางป้อม / เลือกป้อม | คลิกซ้าย | แตะ |
| หมุนกล้อง | คลิกขวาค้างแล้วลาก | สองนิ้วลาก |
| ซูม | ล้อเมาส์ | บีบสองนิ้ว |
| รีเซ็ตกล้อง | ปุ่ม 🎥 หรือ `C` | ปุ่ม 🎥 |

คีย์ลัด: `1–6` เลือกธาตุ · `Space` เริ่มเวฟ · `U` อัปเกรด · `S` ขาย · `T` โหมดเล็งเป้า · `F` ความเร็ว · `P` หยุด · `M` เสียง · `Esc` ยกเลิก

## ระบบธาตุ

| ธาตุ | ราคา | ความสามารถ | ชนะทาง |
|------|------|------------|--------|
| 🔥 ไฟ | 60 | ระเบิดวงกว้าง + เผาไหม้ต่อเนื่อง | 🌪️ ลม |
| 💧 น้ำ | 50 | ทำให้ศัตรูช้าลง | 🔥 ไฟ |
| 🪨 ดิน | 70 | ดาเมจหนัก มีโอกาสทำให้มึนงง | 💧 น้ำ |
| 🌪️ ลม | 55 | ยิงรัวหลายเป้า มีโอกาสผลักถอยหลัง | 🪨 ดิน |
| ✨ แสง | 80 | ลำแสงระยะไกล ทะลุทุกตัวในแนว | 🌑 มืด |
| 🌑 มืด | 75 | สาปให้รับดาเมจเพิ่ม + ดาเมจตาม % HP | ✨ แสง |

- วงจร: **ไฟ → ลม → ดิน → น้ำ → ไฟ** และ **แสง ⇄ มืด**
- ชนะทาง ×1.75 · ธาตุเดียวกัน ×0.5 · โดนแพ้ทาง ×0.65
- ศัตรูทุกตัวมีธาตุประจำตัว ดูแถบ "เวฟถัดไป" เพื่อเลือกป้อมให้ถูกทาง

### การหลอมรวม (Fusion)

อัปเกรดป้อมถึงเลเวล 3 แล้วหลอมรวมกับป้อมเลเวล 3 ต่างธาตุ ได้ป้อมใหม่ที่มีความสามารถของทั้งสองธาตุ
และนับเป็นทั้งสองธาตุเวลาคำนวณความได้เปรียบ — มีทั้งหมด 15 แบบ เช่น
ไอน้ำเดือด (ไฟ+น้ำ), แมกมา (ไฟ+ดิน), พายุหิมะ (น้ำ+ลม), อัสนี (ลม+แสง), สุริยคราส (แสง+มืด)
ป้อมหลอมรวมยัง "ปลุกพลัง" เพิ่มได้อีก 3 ดาว

## ฟีเจอร์อื่น ๆ

- 3 แผนที่ · 3 ระดับความยาก · 30 เวฟ + โหมดไม่รู้จบ · บอสทุก 10 เวฟ
- โหมดเล็งเป้า (หัวแถว/ท้ายแถว/HP มากสุด/ใกล้สุด), เร่งความเร็ว 1–3×, หยุดชั่วคราว
- เสียงสังเคราะห์ด้วย WebAudio, บันทึกสถิติสูงสุดในเบราว์เซอร์

## โครงสร้างโค้ด

```
index.html         หน้าเกม + UI
src/main.js        UI, อินพุต, ลูปหลัก
src/sim.js         ตรรกะเกมทั้งหมด (ไม่ขึ้นกับการเรนเดอร์) — ส่ง events ให้ฝั่งแสดงผล
src/render3d.js    ตัวเรนเดอร์ Three.js: ฉาก, โมเดล, อนุภาค, กล้อง, post-processing
src/data.js        ข้อมูลธาตุ, การหลอมรวม, ศัตรู, แผนที่, ความยาก (ปรับสมดุลเกมที่นี่)
src/audio.js       เสียงเอฟเฟกต์
src/style.css      สไตล์
```
